# CardioTwin India

A research prototype for exploring cardiovascular risk signals from synthetic wearable and EHR-like data. The project includes data generators, patient-grouped model evaluation, a Streamlit dashboard, and architecture and presentation materials.

**Research demo only:** data and labels are synthetic. This is not a medical device or validated risk calculator, and must not be used for diagnosis, treatment, or triage.

## Project files

The complete project is in [`digital-twin-cv-risk/`](digital-twin-cv-risk/README.md). Follow its README (digital-twin-cv-risk/README.md) for info, setup and run instructions.
